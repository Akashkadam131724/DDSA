# DSA — just show up

Daily practice with **Sawta**. No streak anxiety, no perfect solutions first. We show up, pick a problem, and trace it until it makes sense.

## How we work

- Open a problem
- Trace it on paper / in comments before coding
- Write it down in today's file
- Talk through what broke, not just what passed

The win is being here. The rest follows.

## Layout

```
Akash/          ← Akash's daily files
  day-1-22-sep.js
base/           ← older notes, patterns, and solved problems
```

Sawta's files can live beside `Akash/` the same way: one file per day, named `day-N-DD-mon.js`.

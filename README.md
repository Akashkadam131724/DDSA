# DSA — just show up

Daily practice with **Sawta**. No streak anxiety, no perfect solutions first. We show up, pick a problem, and trace it until it makes sense.

## How we work

- **6 days:** 2 new problems. Trace on paper / in comments, then code.
- **1 day:** review the last 5–6 days only. Hide the files, re-trace, say TC/SC. No new problems.
- Talk through what broke, not just what passed.

The win is being here. The rest follows. Tracker: `Akash/daily.md`.

## Layout

```
Akash/          ← Akash's daily files
  day-1-22-sep.js
base/           ← older notes, patterns, and solved problems
```

friends files can live beside `Akash/` the same way: one file per day, named `day-N-DD-mon.js`.
